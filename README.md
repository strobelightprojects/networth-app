# Net Worth Tracker

Net Worth Tracker is a personal finance dashboard that allows users to monitor their assets and liabilities. It features interactive charts, secure data persistence, and an intuitive ledger to analyze their net worth over time.

## Features

- **Interactive Dashboard:** View overall net worth, total assets, and total liabilities.
- **Charts and Visualizations:** See portfolio allocations and historical net worth trends.
- **Data Import:** Easily upload and map spreadsheet data to populate the ledger.
- **Cloud Persistence:** Securely save your financial data to the cloud.
- **Privacy Mode:** Safely obscure sensitive financial metrics when viewing in public environments.

## Running Locally

1. `npm install`
2. Add your environment variables in `.env` based on `.env.example`
3. `npm run dev`

Visit `http://localhost:3000` to use the application.
